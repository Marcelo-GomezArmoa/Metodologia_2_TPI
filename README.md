## Descripción del Proyecto
Este TPI evalúa la evolución profesional de un sistema de gestión de solicitudes académicas, aplicando diagnóstico de calidad interna/externa, identificación de deuda técnica, refactoring seguro con principios SOLID y Clean Code, pruebas y code review.

## Tecnologías Utilizadas
* **Backend:** Python, FastAPI, SQLModel, PostgreSQL.
* **Frontend:** React, Vite, TypeScript.
* **Control de Versiones:** Git, GitHub (con etiquetado de hitos).

## Estructura de Tags en Git
* `estado-inicial`: Versión base con deuda técnica y code smells.
* `estado-refactorizado`: Versión limpia aplicando arquitectura por capas y DTOs.
